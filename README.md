# Lampa для TizenBrew: avi на Samsung без внешних устройств

Модуль [TizenBrew](https://github.com/reisxd/TizenBrew), который открывает Lampa и
запускает на самом телевизоре маленький сервис. Сервис нужен, чтобы играли `.avi`.

## Зачем

Плеер Samsung не открывает контейнер avi по сети. При этом сами дорожки внутри avi
(xvid, divx, mp3, ac3) он играет, если они лежат в matroska: это проверено на
UE50TU7090 (Tizen 5.5). Отдельного компьютера или сервера для перекладки нет,
поэтому она выполняется на самом телевизоре.

## Как устроено

- `service.js`: сервис на Node.js. TizenBrew запускает его на телевизоре, адрес
  `http://127.0.0.1:8898`. Из индекса avi сервис заранее вычисляет виртуальный
  файл matroska: заголовок, таблицу перемотки (Cues) и заголовки блоков. Сами кадры
  он читает из TorrServer диапазонами в момент запроса плеера.
  - Файл не копируется и не перекодируется, место на телевизоре не нужно.
  - Процессор почти не нагружается.
  - Длительность и перемотка работают сразу.
  - Разбор индекса двухчасового фильма занимает меньше секунды.
- `inject.js`: TizenBrew вставляет этот скрипт в страницу Lampa. Скрипт подключает
  общий плагин `https://l.iphub.io/p.js`.
- В `p.js` есть блок `avi_remux`. Перед запуском плеера он проверяет ссылку. Если это
  avi и сервис отвечает, блок подменяет ссылку TorrServer на адрес сервиса.

Код сервиса написан на ES5. Причина: на старых прошивках сервисы Tizen работают на
Node.js 4. Сервис проверен в Node.js 4.9 и со старым API буферов (как в 4.4).

## Что поддерживается

- Видео: MPEG-4 ASP (xvid, divx 4/5, 3ivx и другие) передаётся как
  `V_MPEG4/ISO/ASP`. Другие кодеки передаются как `V_MS/VFW/FOURCC`.
- Звук: mp3, mp2, ac3, dts, pcm и aac. Остальные форматы передаются как `A_MS/ACM`.
- Несколько звуковых дорожек. Дорожки переключаются в плеере Lampa.
- Индексы: обычный `idx1` и OpenDML (файлы больше 1 ГБ).
- Параметр `mode=vfw` в адресе принудительно включает `V_MS/VFW/FOURCC` для видео.
  Он нужен для проверки, если плеер не примет `V_MPEG4/ISO/ASP`.

Не поддерживаются avi без индекса: например, недокачанные файлы. Такой файл можно
разобрать, только если прочитать его целиком.

## Установка на телевизор

1. Откройте TizenBrew. Перейдите в управление модулями и добавьте модуль
   `gh/SpazzRabbit/lampa-samsung-fix`.
2. Откройте модуль Lampa.
3. Чтобы TizenBrew сразу открывал Lampa, включите в настройках TizenBrew:
   - «Настройки автозапуска»: модуль Lampa;
   - «Настройки автозапуска для служб»: Lampa.

У Lampa внутри TizenBrew свои настройки, отдельные от Lampa в MSX. Адрес TorrServer
нужно указать заново. Остальное можно перенести через аккаунт CUB.

## Проверка без телевизора

Тесты лежат в основном проекте рядом с плагином p.js:

```
node tests/avi-remux.test.js samples       # сервис: побайтное сравнение с исходником через ffmpeg
node tests/avi-hook.test.js                # подмена ссылки в p.js
node tizenbrew/service.js 8898             # запустить сервис локально
```

Адреса сервиса:

```
/health                  жив ли сервис
/open?url=<avi>          разобрать файл заранее и описать дорожки
/mkv/<имя>.mkv?url=<avi> виртуальный файл, поддерживает Range и HEAD
/log                     последние строки журнала
```
